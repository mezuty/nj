# Animation workspace (Roblox R15 / MrXen0 rig)

**Start here:** `animation_tools/ANIMATION_PLAYBOOK.md` (method, rig facts, quality gates, how to ask for loops and actions).
Also read `animation_tools/Instructions_For_Animating_ORIGINAL_BRIEF.txt` (the original rules this was built around).

* `animation_tools/` – the toolkit (rig library, per-character generators, bakers, verification scripts). Needs `pip install bpy` (Python 3.11)
  and the rig `.blend` copied to `animation_tools/work/rig.blend`.
* `animations/` – finished, paste-into-Blender scripts (idle loops for Poison Ivy, Harley Quinn, Catwoman, Batman, Starfire + demo punch actions).
